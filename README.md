# dotfiles-public

App configs (WezTerm, herdr, nvim, yazi, theme toggle, Flick) mirrored from a
private dotfiles repo by its `publish.sh`. Edits made here are overwritten.

Clone to `~/.dotfiles`: the files sit at `~/.dotfiles/home/.config/...`, where
`~/.config` links into them, and the theme toggle and WezTerm look for them.
